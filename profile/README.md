<h1 align="center">Damast</h1>
<p align="center"><b>Every commit a layer.</b></p>

Damast is a soft fork of [Forgejo](https://forgejo.org), the self-hosted software forge. It follows every Forgejo release and stays a drop-in replacement in both directions: same data, same config, and a way back at any time.

**What's different**

- **Co-authors:** `Co-authored-by` trailers show up on commits, with avatars and links.
- **Repo-bound packages:** packages belong to a repository. Repo write publishes, repo read downloads, and Actions tokens work out of the box.

**Repositories**

| Repo | What it is |
|---|---|
| [damast](https://github.com/damast-dev/damast) | The server |
| [mast](https://github.com/damast-dev/mast) | The companion CLI (early stage) |
| [damast.dev](https://github.com/damast-dev/damast.dev) | The website |
